---
title: "What counts as drift"
description: "The twelve failures the auditor is measured against, and the four refactors it must stay quiet about."
---

Evaluation runs against a synthetic Go payments API with a committed OpenAPI spec
that matches it exactly in the clean state. Drift is then **injected**, so the
ground truth is known by construction rather than argued about.

## The twelve drifts

| ID | Severity | What changed |
|---|---|---|
| D01 | high | Response field renamed in code, spec unchanged |
| D02 | medium | Handler returns 200, spec documents 201 |
| D03 | high | Endpoint exists in code, absent from spec |
| D04 | high | Spec documents an endpoint that is no longer routed |
| D05 | **critical** | Money field changed from decimal string to `float64` |
| D06 | high | Code requires a field the spec marks optional |
| D07 | high | Query param read as `per_page`, documented as `perPage` |
| D08 | **critical** | Endpoint now requires auth, documented as public |
| D09 | low | Pagination default changed, docs stale |
| D10 | **critical** | Webhook signature header renamed |
| D11 | medium | Validation loosened below the documented constraint |
| D12 | medium | New 429 response undocumented |

## The three that actually hurt

<CardGroup cols={3}>
  <Card title="D05 · Money precision" icon="coins">
    An amount moves from `"1500.50"` to `1500.50`. Partners parsing a string
    break; partners parsing a float lose precision. Ledgers stop balancing months
    later and nobody knows why.
  </Card>
  <Card title="D08 · Silent auth" icon="lock">
    An endpoint documented as public starts requiring a token. Every integrator
    gets a 401 where there was none, against documentation that says otherwise.
  </Card>
  <Card title="D10 · Webhook signature" icon="signature">
    The signature header is renamed. Every delivery now fails verification on the
    receiving end, and the sender sees nothing wrong.
  </Card>
</CardGroup>

<Warning>
  All three are **silent**. The code compiles, the tests pass, the endpoint
  returns 200. The damage lands entirely in the partner's system.
</Warning>

## The four decoys

Refactors that change code without changing the contract: a local rename, an
added comment, an extracted helper, a reordered struct field.

These are what make precision measurable. Without them, an auditor that reports
everything scores perfectly. A finding on any of the four is a false positive.

## Metric

Primary metric is **F1 over verified drift findings** — recall alone rewards
noise, precision alone rewards silence.

Targets committed in writing before the first run, so they cannot be adjusted
afterwards to flatter the outcome:
