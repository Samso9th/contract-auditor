## Built and verified

Every component below is covered by offline tests that run with no API key
(`make test-tools`):

<CardGroup cols={2}>
  <Card title="Route extraction" icon="route">
    `go/ast` walker. Finds 841 routes on the target repository where a grep finds
    805.
  </Card>
  <Card title="Spec index and differ" icon="code-compare">
    Computes code △ spec as a set difference rather than inferring it.
  </Card>
  <Card title="Verification gate" icon="shield-check">
    Generates and runs the Go test that decides every finding.
  </Card>
  <Card title="Model client" icon="plug">
    Provider-neutral, curl transport, JSON extraction that tolerates real model
    output.
  </Card>
  <Card title="Per-endpoint auditor" icon="magnifying-glass">
    The fan-out unit.
  </Card>
  <Card title="Notification layer" icon="bell">
    Slack and Telegram, gated on verification.
  </Card>
</CardGroup>

There is also a scored **no-model run** (`make deterministic`) that establishes
how much of the problem needs no AI at all — the bar the agent layer has to clear
to justify its cost.
