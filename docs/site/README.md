# Mintlify site

Public documentation for Contract Auditor.

```bash
npm i -g mintlify
cd docs/site
mintlify dev
```

Content here is the **public product documentation**. The long-form internal
notes live one level up in [`docs/`](../): `overview.md` (plain-language
explainer) and `self-improvement.md` (design note). Where the two overlap, the
repo docs are the source of truth and these pages are the condensed, web-shaped
version.
